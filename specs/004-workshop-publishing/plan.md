# Plan
Gateway adds a separate admin-only MCP endpoint /mcp/publishing and same-origin /publisher/tools facade for the admin shell. Use owner REST APIs, never domain databases. Structured model drafts use server-side OpenAI Responses credentials and configured model. Strict Zod contracts validate draft content and editor blocks. Existing services already supply the required authoring routes. Publishing records request IDs/steps in an operator-configured durable directory; one gateway process owns that directory, and uncertain steps are never automatically replayed. Browser API uses shell HttpClient authentication and a scoped review VM. Public catalog contracts remain additive and read-only.
Verification: schema/auth/adapter/orchestration failure tests, generated contracts, gateway build/lint/e2e, publisher architecture/types/build/behavior tests. Live model/owner and deployment acceptance recorded separately.

Producer contract discrepancies recorded: generated CreateWorkshopDto marks _id required despite optional runtime behavior; lab test JSON types narrow opaque values and omit arrays. Owner mappings compile against published fields with these scoped exceptions. Sanitizer is locked to 2.17.0 for compatibility with the CommonJS/Jest runtime; parsing/sanitization tests verify encoded URL handling. No unrelated dependency updates.

Test stage failures, privacy and HTTP decoding; run existing gateway checks and publisher architecture/types/build/tests. No automatic paid retries or publication changes.
